Roux Method

发明者：Gilles Roux。

以「块构建」（blockbuilding）为核心的还原方法：先在左、右两侧各搭一座 1×2×3 的「桥」， 再由 CMLL 完成顶角块、LSE 完成剩余六棱。以 M/U 转动为主、无需频繁转体，是高效率的复原方法。

First Block (FB)
在左侧构建 1×2×3 桥：DBL、DFL 角块与 DL、DB、DF 棱。

Second Block (SB)
在右侧构建对称的 1×2×3 桥：DBR、DFR 角块与 DR、DB、DF 棱，仅用 R/M/U 完成。

3
CMLL
保持左右桥不动，一步解决 U 层四角的定向与排列（Corners of Last Layer），42 个 case。
4.1
EOLR
一步完成剩余六棱的定向（EO）与左、右桥末棱（L/R 棱）归位，165 个 case。
4.2
L4E
最后四棱（Last Four Edges）归位，仅用 M/U 转动完成，120 个 case。

Nautilus Method

鹦鹉螺法（Nautilus），发明者：James Straughan。

以「Shell」的起点的还原方法，以EODF变体为例：先构建左桥 + dbr块（俗称Shell），接着用 EODF 完成棱块定向和还原DF块， 完成LS（Last Slot）后进入最后一层，LL完成剩余部分。观察方便、R/U/r 转动适合单手完成。

可提前解决角块排列（CP），使最后一层由 R/U 双轴公式（2GLL）高效完成。

1.1
Shell - 左桥
构建左桥（1×2×3）：DBL、DFL 角块与 DL、DB、DF 棱。

1.2
Shell - dbr Block
在左桥基础上构建 dbr 角块，形成 Shell；dbr 块的处理涉及 DRDB 公式集，16 个 case。
2.1
CP
角块排列（Corner Permutation）：将剩余角块的相对位置一次调整到位，168 个 case。
2.2
EODF
完成全部棱定向（EO）并归位 DF 棱。
to be continue
3
LS
Last Slot：插入最后一组棱角对（FR 槽），使魔方只剩最后一层。
to be continue
4
LL - COLL + EPLL / 2GLL
最后一层：因 CP 已解决，仅用 R/U 即可完成（2GLL）；也可区分为 COLL（角定向）+ EPLL（棱排列）两步。

APB Method

发明者：James Straughan。

以左侧 2×2×3 为起点的块构建方法：先构建 dl Block 与 EO Pair（EO定向和dBR还原），再经 LXS （Last Shot和DR同时还原）进入最后一层， LL完成剩余部分。全程转动路径灵活。

2×2×3 - dl Block
在左侧构建 2×2×3 块：DBL、DFL 角块与 DL、DB、DF 棱。

YruRU Method

发明者：Yash Mehta。

以 CP-Line 为核心的高效方法：先构建 CP-Line（角块排列线），再经 pEO-Extension（部分棱定向扩展）与 EOBF（棱定向块构建）完成 2×2×3， 通过F2L、2GLL完成最后一层。

提前解决角块排列，后段公式高度简化，仅通过 r/U/R/U 可完成。

1.1
CP-Line
构建 CP-Line：dL 一条排列线，并一次解决全部角块的相对排列。

pEO-Extension

EOBF

F2L

LL - OLL + PLL / 2GLL

CEOR Method

发明者：CEOR Group（经过多人研发统一的方法）。

是一种统一后的还原方法，和LEOR、YruRU、APB都有共同指出。

以 CP 为核心：先经 CPFB 一次完成角块排列与左桥，再由 EOdM 定向全部棱块并完成DFDB棱块，随后构建右桥（RB）， 最后因 EO 与 CP 均已解决，仅用 R/U 完成LL。

观察难度属于烧脑级别。

CPFB
CP First Block：一次完成角块排列（CP）与左桥（First Block）的构建。
